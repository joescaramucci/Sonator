# Sonator

WPF desktop scaffold for a local Windows 10 sequencer inspired by classic Notator workflows.

## What is in this first build

- Transport bar
- Pattern list
- Arrange lanes
- Inspector panel
- Piano roll / step sequencer
- Project save/load
- Basic MIDI editing: select a step, edit note, velocity, duration, transpose, quantize
- MIDI output device selection and rescan
- Mouse painting in the piano roll
- Zoomable piano roll
- Copy/paste track steps
- Undo/redo
- Visible playhead on arrange and piano roll
- Persistent track clipboard
- Editable arrange blocks
