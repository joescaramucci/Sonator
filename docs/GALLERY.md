# Sonator Screenshot Gallery

## Application overview

The full Sonator workspace combines pattern arrangement, an eight-track mixer,
transport controls, track parameters, and the VST3 browser.

![Sonator application overview](images/sonator-overview.png)

## Arrange timeline and track mixer

The Arrange editor provides multibar navigation, sixteenth-note and
quarter-note grid lines, timeline zoom, per-track mute and solo, record arm,
volume, and signal meters.

![Arrange timeline and track mixer](images/sonator-arrange-mixer.png)

## VST3 browser

Native editor thumbnails are captured in isolated helper processes and shown
in the integrated VST3 browser.

![VST3 plug-in browser](images/sonator-vst3-browser.png)
